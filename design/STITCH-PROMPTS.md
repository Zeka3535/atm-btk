# Промпты для Google Stitch (UI ATM БТК PWA)

Палитра: primary `#663479`, accent `#33CEE1`, фон `#F5F3F7`, светлая тема, mobile 390×844.

## Экран: Login
Mobile login for telecom field app «ATM БТК». Purple header brand mark, light cards, rounded inputs, primary button «Войти». Beltelecom style #663479 / #33CEE1. Russian labels. No dark theme.

## Экран: Task list
Field service task list with bottom pill navigation island (3 round icons). Task cards with badges Новая (blue), Отписано (orange), Отчёт послан. Address group header «2 заявки». Phone row and map icon. Corporate purple/cyan, light background, rounded 16px cards.

## Экран: Task detail
Task detail with subscriber name, full address, bold description, buttons Позвонить and Карты. Back link. Same palette.

## Экран: Settings
Settings list with toggles: offline simulation, notifications, sound, vibration. Secondary links. Light corporate UI.

Экспорт макетов класть в эту папку (`design/exports/`) при работе со Stitch MCP.
